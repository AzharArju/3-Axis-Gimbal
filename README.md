# 3-Axis-Gimbal

3 rings that have bearings in each ring that allow dowel pins to go through to connect to the next piece.
Intended to help with controls for Baby Ikarus.

Mechanical:
Carbon fiber rods that are cut to about 12 inches each and have printed corner pieces to create a square. Bearings are placed perpendicular to each other on the next ring.
Carbon fiber strips were a little too flimsy to be able to hold the Baby Ikarus without flexing which made this close to unusable.
Does work for small objects though if they're extremely light. Forced me to print Baby Ikarus on close to 3% infill and lower wall settings to make it lighter.

I designed, printed, assembled the entire thing. I cut the carbon fiber strips using a dremel.
